# 📚 Library Management System

A simple desktop library manager application built using **Java Swing, JDBC, and MySQL** in **NetBeans IDE**.

The application is designed to manage library books, users, book issue/return details, and due-fine information through a graphical user interface.

## ✨ Features

* 🔐 User login and registration
* 📖 Add and manage library books
* 🔎 View book details
* 📤 Issue books to students
* 📥 Manage returned and due books
* 💰 Track due-fine details
* 🗄️ MySQL database integration using JDBC

## 🚀 Getting Started

### 📋 Prerequisites

* ☕ Java Development Kit (JDK)
* 💻 NetBeans IDE
* 🐬 MySQL Server
* 🔗 MySQL JDBC Driver

### ▶️ Running the Application

1. 📥 Clone or download this repository.
2. 💻 Open the project in **NetBeans IDE**.
3. 🗄️ Configure the MySQL database connection used by the application.
4. 📊 Make sure the required MySQL database and tables are created with their respective columns and appropriate data types.
5. ▶️ Build and run the project from NetBeans.

## 🎯 Purpose

This project was developed as a Java desktop application to practice building a GUI-based application with **Java Swing**, connecting it to a **MySQL database using JDBC**, and implementing common library-management operations.
